GITHUB MAINTENANCE

This document outlines maintenance procedures for the AI_VIDEO_WEBGL_COMPETENCES repository.

## Repository Maintenance

- **Depot Access**: Maintainers must have admin rights to the depot.
- **Branches**: Use feature branches for changes; merge via pull requests.
- **Labels**: Apply labels like bug, enhancement, or documentation to issues.

## Issue Management

- **Bug Reports**: Use the bug report template to ensure reproducibility.
- **Feature Requests**: Submit via feature request template with clear use cases.
- **Question**: Use the question template for clarifications.

## Workflow Validation

- **CI/CD**: Validate changes via GitHub Actions workflows before merging.
- **Local Testing**: Run LOCAL_VALIDATION.md for pre-submission checks.

## Security

- **Reporting**: Follow SECURITY.md for vulnerability disclosures.
- **Access Control**: Restrict sensitive operations to maintainers only.

## Documentation Updates

- **Clarity**: Ensure all documentation is concise and ASCII-only.
- **Consistency**: Replace words like competences with competences, videos with videos, depot with depot.

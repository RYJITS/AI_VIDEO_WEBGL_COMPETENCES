# Licence A Decider

Le depot ne contient pas encore de licence open source explicite. Sur GitHub, cela signifie qu'il ne faut pas supposer un droit de reutilisation, modification ou redistribution.

## Options Courantes

| Licence | Effet |
|---|---|
| MIT | Tres permissive, simple, compatible avec une reutilisation large |
| Apache-2.0 | Permissive avec clauses explicites sur les brevets |
| CC BY 4.0 | Adaptee aux contenus/documentations, attribution requise |
| CC BY-NC 4.0 | Autorise la reutilisation non commerciale avec attribution |
| Proprietaire / tous droits reserves | Controle maximal, collaboration externe plus limitee |

## Recommandation

Choisir explicitement une licence avant d'encourager des contributions externes ou une reutilisation publique large. Pour ce depot hybride docs + scripts + medias, il peut etre pertinent de separer:

- code/scripts/skills: MIT ou Apache-2.0;
- videos/contact sheets/medias: CC BY 4.0, CC BY-NC 4.0 ou tous droits reserves.
